# Engine Room Records (music.raggiesoft.com)

A modern, persistent audio platform for the RaggieSoft universe.

## Player Requirements
- **WCAG Level AA Compliant:** Accessible controls, keyboard navigation, and semantic HTML.
- **Media Session API:** Integrates with system-level media controls (lock screen, control center) showing title, artist, and album art.
- **Album Art Display:** Prominently features the album artwork while playing.
- **Rock Opera Support:** Flawlessly handles continuous, gapless-style playback across sprawling rock operas that span multiple discs/albums (e.g., The Paper Wall's *Static & Silence*).
